# 🛍️ Noon E-Commerce Website Clone

A frontend e-commerce website inspired by **Noon**, currently under development. This project is being created to practice and improve my skills in **HTML and CSS** while building a real-world e-commerce interface.

## 🚧 Project Status

**In Progress 🚀**

The website is currently under development. More features, sections, and improvements will be added as the project progresses.

## ✨ Current Features

* 🏠 E-commerce homepage
* 🔍 Search bar UI
* 📍 Location section
* 👤 Login section
* 📦 Orders section
* ❤️ Wishlist section
* 🛒 Cart section
* 🌐 Language option
* 🛍️ Product categories
* 🔥 Promotional banners
* 📱 Electronics and mobile sections
* 👗 Fashion sections
* 💄 Beauty section
* 🏠 Home & Kitchen section
* 📞 Customer support section
* 📚 Footer navigation

## 🛠️ Technologies Used

* HTML5
* CSS3
* Font Awesome

## 🎯 Project Goal

The main goal of this project is to recreate a modern e-commerce website interface inspired by Noon and gain practical experience in frontend web development, webpage layouts, navigation bars, product sections, and responsive design.
